        Help

        1. Connect the board — power it on; it joins your WiFi (IP shows on its serial monitor, or see the Nodes tab). First boot: connect to the AudioNode-Setup WiFi and open http://192.168.4.1.
        2. Find it here — Nodes tab → Find boards on WiFi scans your network for Espressif boards; click Add on one. Or type its IP and press Add.
        3. Play — Player tab → choose a library folder → click a file → Play. Audio streams to every node in the Nodes list (UDP :1234).
        4. Equalizer — EQ tab → Enable, pick a preset or move sliders (changes apply live; a tiny tick = pipeline restart). Save… stores your own preset.
        5. Board not found? Same WiFi as this PC, no AP-isolation on the router, and Windows firewall must allow python (UDP out is default-allow).

        About

        AudioPlayer — browser audio server for ESP32 AudioNode boards.

        RTP L16 over UDP (48 kHz, 16-bit, mono, 20 ms frames) — one ffmpeg pipeline per stream. Board = UDP listener; source IP is whitelisted in firmware.

        Gain chain: 65 Hz highpass, −3 dB bass shelf @120 Hz, compressor, limiter @0.5 (board ×2 digital gain ⇒ DAC never clips). EQ: 10-band VLC grid, limiter stays last.
